# Accessing Deployed App:

The web app has been deployed (for free) using Streamlit's Community Cloud hosting services and can be accessed using: https://stockmanager-app-123.streamlit.app/

Due to it being a free provider, the app can often go to sleep and requires clicking on the 'Wake app up' button when prompted. After a few minutes the app should be up and running.

# Accessing App Locally:

To run the app locally it is important to have Python installed on the local machine along with necessary packages (available in requirements.txt file). Once installed, the app can be run using `streamlit run app.py`
